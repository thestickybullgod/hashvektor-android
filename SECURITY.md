# Security policy

## Reporting a vulnerability

Please report security vulnerabilities privately through GitHub's private vulnerability
reporting feature for this repository. Do not open a public issue, Discussion, or pull request
containing sensitive vulnerability details.

Include as much of the following information as is useful:

- The affected component or screen
- Android and app versions
- Steps to reproduce
- Impact and likely threat model
- A minimal proof of concept
- Suggested remediation, if available

## Scope

Security reports should cover:

- Hashing and integrity result correctness
- Native BLAKE3 integration
- Storage Access Framework and incoming intents
- Google Play Billing and entitlement handling
- APK and app signature verification
- Manifest permissions and exported components
- Privacy, logging, backup, and data handling

Do not test beyond controlled accounts or devices you own or are authorized to use.
